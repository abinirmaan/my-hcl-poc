# Client demo guide

Recommended duration: 12–15 minutes.

## Before the meeting

1. Start the app in Cloud Shell and open port 8080.
2. Keep Demo Engine selected for the first walkthrough.
3. Generate the supplied login example once to warm up the UI.
4. Refresh and begin the client session from the Requirement tab.

## Walkthrough

1. **Requirement input**: explain that the app accepts a requirement, user story, or specification.
2. **Configuration**: choose six test types and 12 cases.
3. **AI analysis**: show extracted rules, constraints, and questions for the product owner.
4. **QA review**: accept one case, edit one expected result, reject one case, and regenerate one case.
5. **Coverage**: show requirement traceability, test-type distribution, confidence, and quality findings.
6. **Export**: download the approved suite as Excel.
7. **Close**: describe the POC measurements: effort reduction, coverage, reviewer acceptance, and additional useful scenarios.

## Important positioning

- The 50–70% effort reduction is a hypothesis to validate with client data.
- Human approval remains mandatory.
- Jira and TestRail writeback belong to a production extension.
- Vertex AI provides live generation; Demo Engine protects the meeting from access or network issues.
